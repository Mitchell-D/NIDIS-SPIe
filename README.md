# NIDIS-SPIe

scripts supporting the NIDIS effective precipitation project

## acquire\_uscrn\_subhourly.py

Given a list of stations, download sub-hourly CSVs for all available
years in a provided range, and optionally concatenate them across
years.

## extract\_uscrn\_pkl\_hourly.py

Given a csv containing multiple stations' hourly data, parse data
into a dictionary mapping stations to variables, and variables to
numpy arrays. Both the numpy array type and the variable names are
determined based on a configuration mapping the input variable names
(defined in the csv header) to the new variable names, the dtype, and
a conversion function to parse from text to the dtype.

The subsequent arrays should be guaranteed to be uniform-size, but
are not locked to a consistent time step.

## extract\_uscrn\_pkl\_subhourly.py

similar to the hourly version, except that each station is extracted
into a separate pkl file.

## parse\_uscrn\_hourly\_pkl\_to\_zarr.py

Given an hourly pkl generated by `extract_uscrn_pkl_hourly.py`,
a start and end time, zarr chunking parameters, and lists of
variables to retain, defines a regular-interval hourly time domain,
round each observation to the nearest hour, and assign it to the
corresponding position in the regular array.

An error will be raised if a data value would overwrite a separate
observation already stored for the same variable/hour.

## parse\_uscrn\_subhourly\_pkl\_to\_zarr.py

Given a per-station pkl from `extract_uscrn_pkl_subhourly.py`, snap
data to a regular hourly grid, and calculate the minimum, maximum,
average, standard deviation, and number of valid observations per
hour.

## check\_ghcnd\_inventory.py

Given a GHCN daily inventory text file from [this link][1], find
stations within a degree distance threshold of USCRN stations with
coordinates specified in a zarr file, and download their PoR csv
files. Save a mapping from crn stations to the closest ghcn stations
alongside the ghcn periods of record and distances.

## parse\_ghcn\_daily\_to\_zarr.py

Extract GHCNd station period-of-record files to a zarr file with
groups for each station.

## calc\_spi\_dists.py

Fit distributions with multiple window values to ghcn stations,
and calculate sum of squared errors, anderson-darling fit, and Akaike
information criterion. Save the distribution parameters, error
statistics, histograms, and information on zero-precip periods to
each station's zarr group.

[1]:https://www.ncei.noaa.gov/pub/data/ghcn/daily/ghcnd-inventory.txt
